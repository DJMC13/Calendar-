# Calendario de Reuniones · Prototipo

Prototipo frontend (React + Vite + Tailwind). Sin base de datos: los datos viven en memoria y se reinician al recargar.

Requisitos: Node.js 18+ y pnpm (`npm i -g pnpm` o `corepack enable`).

```powershell
pnpm install
pnpm dev
```

Abre la dirección que muestre la consola (normalmente http://localhost:5173). Versión estática: `pnpm build`.

Los datos de ejemplo (proyectos, áreas, colaboradores y reuniones) están en `src/data.js`.
